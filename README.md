# Портал оператора — Матриус

Обучающий сайт для новых операторов первой линии. Содержит материалы онбординга, регламенты, скрипты и инструкции по работе с CRM GetCourse.

**Деплой:** [call-training.vercel.app](https://call-training.vercel.app)

## Содержание

- **Онбординг** — структура звонка, антироботные техники, работа с временными слотами
- **Регламент** — должностные обязанности, скрипты, работа с возражениями, техническая поддержка
- **GetCourse** — инструкции по работе с CRM: учёт заявок, статусы, поля, типовые сценарии
- **Шпаргалка** — быстрый справочник по ключевым моментам звонка
- **Работа с негативом** — инструкции для сложных ситуаций

## 🔐 Безопасность и защита данных

### Никаких персональных данных на сайте

- Портал — **чистый статический HTML/CSS/JS**: он не принимает, не хранит и не передаёт персональные данные операторов или клиентов
- **Нет форм**, нет обработки ввода, нет backend'а — на сайт ничего нельзя «сдать» злоумышленнику
- Инструкции по GetCourse — это **обучающий контент** (текст и скриншоты), а не живая интеграция с CRM: доступ к реальным данным платформы через портал невозможен

### Защита контента и канала

- Сайт раздаётся по **HTTPS** (Vercel) — шифрование трафика по умолчанию
- Репозиторий приватный/контролируемый — внутренние регламенты не публикуются в открытый доступ без необходимости
- Скрипты работают без внешних зависимостей — нет сторонних CDN, минимизирован supply-chain риск
