# Портал оператора — Матриус

Обучающий сайт для новых операторов первой линии.

**Деплой:** [call-training.vercel.app](https://call-training.vercel.app)

## Содержание

- **Онбординг** — структура звонка, антироботные техники, работа с временными слотами
- **Регламент** — должностные обязанности, скрипты, работа с возражениями, техническая поддержка
- **Шпаргалка** — быстрый справочник по ключевым моментам звонка
- **Работа с негативом** — инструкции для сложных ситуаций

## Технологии

Статический сайт на HTML/CSS. Деплоится автоматически через Vercel при пуше в `main`.

## Обновление контента

Контент синхронизируется из Notion через пайплайн в основном репозитории проекта ([operator-support-bots](https://github.com/Jane-547/operator-support-bots)). Ручное редактирование HTML-файлов — напрямую в этом репо.
