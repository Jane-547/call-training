CRM и слоты

Работа со слотами встреч и сделками в ГетКурсе: создание, статусы, фиксация.

Работа со слотами

Слоты — временные окна для диагностических сессий. Запись, отмена и изменения проводятся только через CRM.

1

Просмотр слотов

Зайти в Админку → раздел «Расписание» → выбрать нужного специалиста → просмотреть доступные слоты.

2

Запись клиента в слот

  • Убедиться, что слот свободен.
  • Открыть сделку клиента в CRM.
  • Выбрать подходящий слот — после подтверждения слот закрывается для других.
  • Уведомить клиента о времени встречи.
  • Зафиксировать в CRM: статус «Встреча назначена», дата и время.
3

Если нет подходящего слота

Уточнить у руководителя, когда откроются новые. Не обещать клиенту конкретное время самостоятельно.

4

Отмена записи

Только через CRM. После отмены слот снова становится доступным. Причину отмены обязательно фиксировать.

Работа со сделками в ГетКурсе

Инструкция по работе со сделками в CRM ГетКурс. Никогда не удалять сделки — только менять статус.

1

Создание сделки

  • Зайти в раздел «Сделки».
  • Нажать «Создать сделку».
  • Заполнить поля: имя клиента, телефон, источник заявки.
  • Установить начальный статус.
2

Обновление статуса

После каждого контакта с клиентом обновлять статус сделки:

  • Новая заявка → В работе
  • В работе → Встреча назначена (после записи на диагностику)
  • Встреча назначена → НДЗ (если не пришёл)
  • Встреча состоялась → Ожидает решения
  • Ожидает решения → Оплатил / Отказ
3

Фиксация контактов

В каждой сделке вести лог: дата, время, способ контакта, результат, следующий шаг.

Важные правила
  • Никогда не удалять сделки — только менять статус.
  • Дублирующие сделки объединять через руководителя.
  • Комментарии писать понятно — их читают коллеги и руководитель.
  • Дату следующего касания всегда проставлять.
